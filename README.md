# Ivanvolt

Indie hacker in Hubei. I run a one-person company and ship my own products.

## 🧩 Open source

- [printresize-skill](https://github.com/ivanvolt-labs/printresize-skill): an agent skill that turns images into print files with the PrintResize API
- [openclaw-lumecoder-auth](https://github.com/ivanvolt-labs/openclaw-lumecoder-auth): plug Lumecoder into OpenClaw as a provider
- [saas-base-template](https://github.com/ivanvolt-labs/saas-base-template): a starter kit for getting a SaaS online without rebuilding auth, billing, and the usual scaffolding
- [ivan-wallpaper-wechat](https://github.com/ivanvolt-labs/ivan-wallpaper-wechat): a WeChat mini program for browsing and saving wallpapers
